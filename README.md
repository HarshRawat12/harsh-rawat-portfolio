# Harsh Rawat — Portfolio

An animated portfolio for Harsh Rawat, built with React, GSAP and React Three Fiber.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

The static production site is generated in `dist/` and can be deployed to Vercel, Netlify, Cloudflare Pages or any static host.
